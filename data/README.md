# 本地数据位置

本目录用于人格材料、人物档案、记忆数据库与其他本地数据。

原始聊天导出保留在 `../../humanClone/exports/`；由这些材料生成的人格档案、证据摘录和试验结果可以保存在本目录。

本目录除本说明外的内容默认被 Git 忽略。

## 私人数据与公开示例

- 私人聊天及其衍生内容只用于个人本地试验，不随开源项目发布。衍生内容包括人物档案、记忆、对话摘录、生成的技能文件、向量索引及包含这些信息的运行日志。
- 公开演示使用独立创作的虚构人物材料，或已确认数据许可的公开数据集。不要从私人聊天改名改写来制作公开示例。
- 公开数据集可以下载到 `data/public/`，该目录也默认被 Git 忽略。仓库可以提供下载、适配和评测代码；需要随仓库分发的少量样例放在 `examples/`，并附上来源、数据许可与修改说明。
- 私人数据的路径由本地配置指定，示例配置不填写个人账号、联系人或私人文件的具体名称。

后续导入路径、存储结构与备份方式在 NPC 层设计时确定。
