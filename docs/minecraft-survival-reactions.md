# 自卫与受伤补给修正（2026-10-04）

当前问题不只是大模型慢：旧身体在平地单怪、双怪考场已经能完成击杀，但在退路受阻或残血补给时会作出无效反应。本次保留 pi 规划和 50ms 本地控制循环，只修改具体反应策略。

- **撤退受阻立即换反应。** `retreat_blocked`、`no_retreat_direction` 首次真实失败就封锁本次遭遇的撤退，不再等三次无进展。仍有 `defend` 授权时进入 `combat` 的 `hold` 姿态，只对进入实际近战距离的目标反击，不追击；保持原遭遇起点、活动半径、攻击冷却和控制权。已有目标过期、人工停止、死亡和取消规则继续生效。
- **减少无效切换。** 当前防卫目标仍可见、存活且在局部威胁范围内时，保留该目标，避免两只怪物的距离排序变化反复取消追近。新出现的近处苦力怕和低血量撤退仍优先；目标失效必须重新选择。
- **受伤时准备回血。** 新增 `policy.healBelow`，默认生命值低于 18 且饥饿值未满时，在无可见近敌、有安全食物且允许 `eat` 的窗口主动进食。设为 0 可以关闭这条规则；原 `eatBelow` 饥饿阈值独立保留。消费和库存变化仍需真实确认，不把发出进食指令算成恢复生命。

LLM 可以通过 `body_plan` 明确指定 `combat.stance: "hold"`，并在观察中的 policy 摘要查看受伤补给阈值。遇到无法撤退且未授权反击的情况，身体报告失败并等待规划，不自行扩大权限。
